# AnyDesk IP Resolver

Herramienta de consola para Windows que muestra la IP de la persona que se conecta a tu AnyDesk.

## Qué hace

- Escanea las conexiones TCP y UDP de los procesos de AnyDesk en tiempo real.
- Separa conexiones directas, LAN y relay, con nivel de confianza.
- Muestra país, ciudad e ISP de cada IP.
- Detecta tu propia IP pública para no confundirla con la del otro.
- Opción de mandar cada detección a un webhook de Discord.
